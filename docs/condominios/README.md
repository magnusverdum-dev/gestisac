## Como usar no desenvolvimento

1. Usar as prompts do ficheiro `01-...` como base funcional e de UX.
2. Atualizar a tabela no ficheiro `02-...` conforme avancam os tickets:
   - `Pendente`
   - `Em progresso`
   - `Implementado`
   - `Validado`
3. Em cada sprint, revisar a matriz para confirmar cobertura funcional.
