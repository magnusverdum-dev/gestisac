# Roadmap

## Fase 1: Fundacao

- Documentacao base.
- Estrutura de projeto.
- Design system inicial.
- UX dashboard-first.
- Arquitetura frontend e backend.
- Modelos de dados iniciais.
- Roles e permissoes.
- Mock data.

## Fase 2: Arquitetura Visual

- Sistema de hierarquia visual.
- Composicao premium do dashboard.
- Glassmorphism como arquitetura de superficie.
- Motion language.
- Regras responsivas.
- Primitivas UI reutilizaveis.
- Tokens iniciais em `packages/ui`.

## Fase 3: App Shell

- Scaffold Qwik City.
- AppShell com sidebar e topbar.
- Dashboard visual baseado na referencia.
- Cartoes dos quatro modulos.
- Quick actions.
- Avisos operacionais e prioridades urgentes.

## Fase 4: Backend Base

- Scaffold Rust Axum.
- Configuracao PostgreSQL.
- Estrutura modular.
- Auth inicial.
- Tenant context.
- Health checks.

## Fase 5: Modulos Core

- Condominios.
- Fracoes.
- Residentes.
- Contabilidade base.
- Tickets.
- Documentos.
- Relatorios iniciais.

## Fase 6: Expansao Premium

- IA e automacoes.
- OCR documental.
- Pagamentos.
- Portais de residentes.
- Portais de fornecedores.
- Assembleias digitais.
- Analytics avancado.
- Notificacoes inteligentes.
