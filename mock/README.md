# Mock Data

Dados ficticios para orientar UX, design system e implementacao antes da API estar pronta.

## Ficheiros

- `dashboard.json`: estado inicial do dashboard premium baseado na referencia visual.
- `demo-data.json`: fonte principal da demo cliente, usada pelo frontend e pela API mock/Rust.

## Regras

- Usar dados realistas para condominios portugueses.
- Evitar mocks genericos sem valor de produto.
- Representar estados importantes: sucesso, atraso, urgencia, pendente e concluido.
- Manter os mocks alinhados com os quatro modulos centrais.
