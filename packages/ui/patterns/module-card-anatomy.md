# Module Card Anatomy

## Structure

```text
ModuleCard
  BackgroundAtmosphere
  Header
    IconTile
    TitleGroup
    ContextMenu
  MetricRow
    MetricBlock
    MetricBlock
    MetricBlock
    MetricBlock
  VisualAnchor
  Footer
    PrimaryAction
    StatusBadge
```

## Required Behavior

- Whole card can be clickable only if it does not conflict with internal actions.
- Primary CTA must be keyboard accessible.
- Menu is optional but position must be consistent.
- VisualAnchor cannot obscure metrics.

## Content Limits

- Title: 1 to 2 words.
- Subtitle: 1 short phrase.
- Metrics: max 4.
- CTA: 1 main action.
- Badges: max 2 visible.

## Visual Anchors

Examples:

- Condominios: premium building illustration.
- Contabilidade: wallet, coin or financial ring.
- Administracao: tool case or operational symbol.
- Relatorios: chart, pie or intelligence visual.
