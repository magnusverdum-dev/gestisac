# Responsive Rules

## Desktop

- Sidebar fixed.
- Topbar sticky inside main area.
- Dashboard grid 2x2.
- Alert strip horizontal.
- Wide cards with visual depth.

## Tablet

- Sidebar compact or drawer.
- Quick actions 2x2.
- Module cards 1 or 2 columns.
- Reduce secondary topbar actions.

## Mobile

- Drawer navigation.
- Topbar compact.
- Quick actions compact grid or horizontal scroll.
- Module cards stacked.
- Alert cards stacked.
- Tables become entity cards where possible.

## Text

- No viewport-based font scaling.
- Avoid long labels in buttons.
- Truncate only secondary text.
- Primary values must remain fully readable.

## Touch

- Minimum target: 44px.
- Avoid tiny icon-only actions without tooltip or label context.
- Spacing must prevent accidental taps.
