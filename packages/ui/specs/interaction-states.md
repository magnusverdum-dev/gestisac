# Interaction States

## Universal States

Every interactive component must define:

- default
- hover
- focus-visible
- active
- loading
- disabled

## Hover

Use:

- Slight elevation.
- Stronger border.
- Contextual glow.
- CTA reveal when useful.

Avoid:

- Large movement.
- Layout shift.
- Excessive scale.

## Focus Visible

Use:

- Clear ring.
- High contrast.
- Offset where needed.

Focus must be visible on glass backgrounds.

## Active

Use:

- Slight compression.
- Reduced elevation.
- Immediate feedback.

## Loading

Use:

- Button inline loading.
- Skeleton for cards.
- Shimmer only when subtle.

Avoid large dashboard spinners.

## Disabled

Use:

- Reduced opacity.
- No glow.
- Cursor and aria state aligned.

Disabled text must remain readable.
