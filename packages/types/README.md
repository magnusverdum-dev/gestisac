# Types Package

Pacote planeado para tipos e contratos partilhados.

## Conteudo Futuro

- Tipos de dominio.
- DTOs partilhados.
- Contratos API.
- Enums de roles, permissoes e estados.

## Regra

Tipos partilhados devem ser estaveis, pequenos e orientados a contratos. Tipos internos de implementacao devem ficar dentro da app correspondente.
