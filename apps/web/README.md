# Web App

Futuro frontend GESTISAC.

## Stack Planeada

- Qwik
- Qwik City
- TypeScript
- Tailwind CSS
- Sistema UI premium proprio

## Preview Atual

O dashboard premium ja pode ser visualizado localmente com:

```bash
pnpm run dev:web
```

URL:

```text
http://127.0.0.1:5173
```

## Responsabilidade

Esta app sera responsavel pela experiencia visual, navegacao, dashboard, modulos operacionais e interfaces responsivas.

## Principios

- Dashboard-first.
- Mobile-first.
- Performance-first.
- Componentes reutilizaveis.
- Tabelas apenas como detalhe secundario.
- Design alinhado com a referencia visual premium enviada.
- Implementacao orientada pelos docs de arquitetura visual e specs de `packages/ui`.
